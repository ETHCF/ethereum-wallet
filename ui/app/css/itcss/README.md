### Deprecated
The [itcss](https://www.freecodecamp.org/news/managing-large-s-css-projects-using-the-inverted-triangle-architecture-3c03e4b1e6df/) folder is deprecated. The infrastructure here is from a former era of the extension. The files and some sporadic styling are still used in the codebase but should not be extended. Valid styles will gradually move from this folder into [`ui/app/css`](..). Eventually the itcss folder will be removed.
