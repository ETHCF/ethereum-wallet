# Add Custom Build to Firefox

Go to the url `about:debugging`.

Click the button `Load Temporary Add-On`.

Select the file `dist/firefox/manifest.json`.

You can optionally enable debugging, and click `Debug`, for a console window that logs all of MetaECF's processes to a single console.

If you have problems debugging, Mozilla's extension workshop documents the
[debugging tools](https://extensionworkshop.com/documentation/develop/debugging/).

For longer questions, use the StackOverflow tag `firefox-addons`.
